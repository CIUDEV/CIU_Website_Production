## How to use this folder

1. Open the page file that matches the section you want to review (e.g. `01-home.md`).
2. Mark corrections in a shared doc, email, or directly in comments to the web team.
3. Pay special attention to **`99-items-to-review.md`** — flagged placeholders, forms not yet connected, and naming inconsistencies.
